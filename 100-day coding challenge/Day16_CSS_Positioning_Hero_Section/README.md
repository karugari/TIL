## 1. Flexbox 실전 적용 (L:121 - 122)
flexboxsms 부모(Conrainer)에게 명령을 내릴 때 시작됨
justify-content에서 flex-end 와 end의 차이는 무엇일까에대한 답
- **`flex-end`**: 거의 모든 브라우저(아주 오래된 버전 포함)에서 완벽하게 지원
- **`end`**: 최신 브라우저에서는 잘 작동하지만, 몇 년 된 구형 브라우저에서는 인식을 못 할 수도 있음.

```css
header {

  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 15px 60px;

}
```
- **`display: flex`**: 헤더 내부의 로고(`div`)와 메뉴(`nav`)를 가로로 나란히 세웁니다.
- **`justify-content: space-between`**: 로고는 왼쪽 끝, 메뉴는 오른쪽 끝으로 밀어내어 가운데 빈 공간을 만듭니다.
- **`align-items: center`**: 로고의 높이와 메뉴의 높이가 달라도 수직 중앙에 딱 맞게 정렬합니다.
## 2. 배경 이미지와 히어로 섹션 (L:123 - 124)
### 1. HTML 구조 정의: 의미 있는 ID 부여
`<secion id ="hero">` : 페이지 상단의 대형 이미지와 메인 문구가 들어가는 '주인공' 섹션
**`<section id="highlights">`**: 추천 여행지 카드가 들어갈 섹션입니다.
### CSS 배경이미지의 특징
HTML의 `<img>` 태그는 문서 흐름(Flow)을 차지하여 다른 요소를 옆이나 아래로 밀어내지만, **CSS 배경 이미지**는 요소의 '바닥'에 깔립니다. 덕분에 그 위에 글자나 버튼을 자유롭게 올릴 수 있습니다.
```css
#hero { height: 800px; /* 이미지를 보여줄 충분한 공간 확보 */ 
background-image: url("images/places/ocean.jpg"); /* 이미지 경로 설정 */ }
```

| 속성 | 값 | 설명 |
|---|---|---|
|height|800px|섹션 자체의 높이를 지정해야 배경 이미지가 노출될 공간이 생깁니다.|
|background-position|center|이미지의 중심부를 컨테이너 중앙에 맞춥니다. (서퍼가 중앙에 오게 함)|
|background-size|cover|이미지가 잘리더라도 **요소 전체를 빈틈없이 덮도록** 크기를 조절합니다.|
```css
#hero-content {
    width: 900px;
    background-color: rgba(51, 47, 47, 0.8);
    box-shadow: 2px 4px 8px rgb(68, 67, 67);
    border-radius: 8px;
    text-align: center;
    padding: 50px 0;
    margin: 0 auto;

}
```
박스 중앙 정렬의 두 가지 방법
1. 텍스트 및 인라인 요소 정렬
**`text-align: center`**: 컨테이너 내부의 글자들과 링크(인라인 요소)를 가로 중앙으로 정렬합니다.
2. 블록요소(박스 자체)정렬
margin: 0 auto 박스 모델의 원리를 이용한 기법 상하는 0 좌우는 auto 로 설정해 브라우저가 남은 공간을 절반으로 나누어 좌우에 배분함으로 박스 자체가 중앙으로 이동됨

## 3. 포지셔닝의 마법
### 1. 문서 흐름(Document Flow)과 Static

웹 페이지의 요소들은 기본적으로 HTML에 작성된 순서대로 차곡차곡 쌓입니다. 이를 **문서 흐름**이라고 합니다.

- **`position: static` (기본값)**: 모든 요소의 태생적 상태입니다. 이 상태에서는 `top`, `bottom`, `left`, `right` 같은 좌표 속성을 입력해도 **아무런 반응을 하지 않습니다.** * **특징**: 마치 땅에 박힌 말뚝처럼 정해진 순서대로 자리를 지킵니다.
### 2. 상대적 위치 지정: `position: relative`

요소를 현재의 위치를 기준으로 **살짝 이동**시키고 싶을 때 사용합니다.

- **작동 원리**: 요소가 원래 있어야 할 자리를 기억한 상태에서, 시각적으로만 상하좌우로 이동합니다.
    
- **중요 포인트**: 요소가 이동해도 **원래 차지하던 공간은 그대로 비어 있습니다.** 즉, 주변 요소들은 해당 요소가 이동했다는 사실을 모른 채 원래 자리에 있는 것처럼 행동합니다.
    

### 좌표 속성의 방향 (헷갈림 주의!)

- **`top: 20px`**: 윗면에서 20px만큼 **밀어냅니다.** (즉, 아래로 이동)  
- **`bottom: 20px`**: 아랫면에서 20px만큼 **밀어올립니다.** (즉, 위로 이동)
- **`left: 40px`**: 왼쪽 면에서 40px만큼 **밀어냅니다.** (즉, 오른쪽으로 이동)
### 3. 'Travel Goals' 프로젝트 적용

히어로 섹션의 콘텐츠 박스를 배경 이미지의 중앙 부근으로 내리기 위해 이 지식을 활용했습니다.
```CSS
#hero-content {
    /* ... 이전 스타일들 ... */
    position: relative; /* 1. 포지셔닝 모드 활성화 */
    top: 200px;        /* 2. 원래 위치에서 아래로 200px 이동 */
}
```

이렇게 하면 마진을 복잡하게 계산할 필요 없이, 원래 위치에서 깔끔하게 원하는 만큼 박스를 내려줄 수 있습니다.
웹사이트에서 가장 먼저 눈에 띄어야할 h1과 이를 보조하는 p태그의 대비를 확실히 줌

### 1. position: absolute (유령 요소)

`absolute`는 말 그대로 요소를 일반적인 문서 흐름에서 **'완전히 제거'**합니다.
- **특징**: 요소가 공중에 떠버리기 때문에, 뒤에 있던 요소들이 해당 요소가 원래 없었던 것처럼 자리를 차지하고 위로 올라옵니다.
- **기준점**:
    - 가장 가까운 **부모(조상) 요소 중 `position: relative`가 적용된 요소**를 기준으로 좌표(`top`, `left` 등)를 잡습니다.
    - 만약 그런 부모가 없다면 최상단인 `<html>` 요소를 기준으로 삼습니다.
        
- **프로젝트 적용**: 헤더를 `absolute`로 설정하면, 그 아래에 있던 히어로 섹션(배경 이미지)이 헤더를 무시하고 맨 위로 올라와 헤더와 겹치게 됩니다.

### 2. position: fixed (껌딱지 요소)

`fixed`는 요소가 사용자의 화면(시야)에 딱 붙어 있게 만듭니다.

- **특징**: `absolute`처럼 문서 흐름에서 빠지지만, 기준점이 다릅니다.
- **기준점**: **뷰포트(Viewport)**, 즉 우리가 지금 보고 있는 브라우저 화면 그 자체가 기준입니다.  
- **스크롤 효과**: 페이지를 아무리 길게 내려도 `fixed`된 요소는 화면의 정해진 위치에 계속 머뭅니다. (상단 고정 메뉴바의 정석!)

---

### absolute vs fixed 한눈에 비교

|**구분**|**absolute (절대 위치)**|**fixed (고정 위치)**|
|---|---|---|
|**문서 흐름**|제거됨 (공중에 뜸)|제거됨 (공중에 뜸)|
|**기준점**|`relative`가 있는 가장 가까운 부모|**뷰포트** (현재 화면 창)|
|**스크롤 시**|페이지와 함께 위로 올라감|**화면에 고정되어 따라옴**|
|**주요 용도**|이미지 위 글자 겹치기, 아이콘 배치|상단 네비바, 하단 'Top' 버튼|

##  실전 팁: 뷰포트(Viewport)란?
스크립트에서 강조된 **뷰포트**는 웹사이트 전체의 길이가 아니라, **"지금 내 눈에 보이는 브라우저 영역"**을 의미합니다.
- `absolute`는 **웹사이트의 시작점**에 붙으려고 하고,
- `fixed`는 **내 눈앞의 시작점**에 붙으려고 합니다.
  
이 차이 때문에 스크롤을 내릴 때 하나는 사라지고, 하나는 유지됨
