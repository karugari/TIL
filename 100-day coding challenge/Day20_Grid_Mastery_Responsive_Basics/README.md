
## 1. 그리드 실전 적용
부모요소인 ul에 그리드 시스템 도입
```CSS
ul{
display: grid;
grid-template-columns:1fr 1fr; /*사용 가능 공간을 정확히 2등분함*/
gap: 20px;  /* 행과 열 사이에 일정한 간격을 줌*/
}

li:nth-of-type(3){
grid-column: 1 / span 2 /*1번 라인에서 시작하여 2칸차지*/
}
```
### Working with Unicode UTF-8
`meta charset="UTF-8"`의 역할

HTML 파일 상단에 항상 적어주던 이 코드는 "이 페이지는 전 세계의 거의 모든 문자와 기호를 표시할 수 있는 UTF-8 표준을 따릅니다"라는 선언입니다. 이 덕분에 브라우저는 특수 기호를 해석할 수 있음
#### 1. 십육진법 문자 참조 (Hexadecimal Reference)

화살표를 표현하기 위해 사용한 `&#x2192;`는 암호 같아 보이지만 정해진 규칙이 있습니다.
- **`&`**: 문자 참조의 시작을 알림.
- **`#x`**: 십육진법(Hexadecimal) 숫자를 사용하겠다는 의미.
- **`2192`**: 오른쪽 화살표(→)에 할당된 유니코드 번호.
- **`;`**: 참조의 끝을 알림.

#### 2. 왜 아이콘 이미지보다 유니코드가 좋을까?
- **성능**: 별도의 이미지 파일을 불러올 필요가 없어 페이지 로딩이 빠릅니다.
- **유지보수**: 텍스트 색상(`color`)이나 크기(`font-size`)를 CSS로 조절하면 화살표도 똑같이 변합니다.
- **호환성**: 모든 현대 기기와 브라우저에서 동일하게 보입니다.
## 2. 반응형 디자인의 서막 
### 1. 반응형 웹 디자인 입문
#### 1.1. 왜 반응형(Responsive)인가?

과거에는 PC용 사이트와 모바일용 사이트를 따로 만들기도 했지만, 지금은 하나의 코드로 모든 기기에 대응하는 것이 표준입니다.
- **목표**: 데스크탑, 노트북, 태블릿, 스마트폰 등 사용자가 어떤 환경에서 접속하더라도 최상의 사용자 경험(UX)을 제공하는 것.

#### 1.2. 이번 모듈에서 배우는 핵심 기술

- **미디어 쿼리 (Media Queries)**: 브라우저의 너비를 감지하여 특정 크기 이하(또는 이상)일 때만 적용될 CSS 규칙을 정의하는 마법 같은 도구입니다.
- **사이드 드로워 (Side Drawer)**: 화면이 좁은 모바일에서 메뉴 버튼을 눌렀을 때 옆에서 쓱 나타나는 내비게이션 바를 구현합니다.
- **유동적 레이아웃 (Fluid Layouts)**: 고정된 픽셀(`px`) 대신 상대적인 단위나 유연한 그리드를 사용하여 화면 크기에 따라 요소가 자연스럽게 변화하게 만듭니다.

### 2. 반응형 디자인의 3대 변화 요소
사용자가 브라우저의 너비를 줄일 때(데스크탑 → 태블릿 → 모바일), 사이트는 다음과 같이 지능적으로 대응합니다.

|**구분**|**데스크탑 모드 (Wide)**|**모바일 모드 (Narrow)**|
|---|---|---|
|**타이포그래피**|크고 시원한 제목|화면을 가리지 않는 적절한 크기|
|**카드 레이아웃**|**가로 배치** (Side-by-Side)|**세로 배치** (Stacked)|
|**내비게이션**|메뉴 항목이 상단에 노출|**햄버거 아이콘** 내부로 숨김|
### 3. 브레이크포인트(Breakpoint)와 개발자 도구
스크립트에서 마우스로 너비를 줄이다가 '어느 한계점'에서 레이아웃이 확 바뀌는 것을 보셨을 거예요.

- **브레이크포인트**: 디자인이 변경되는 특정 너비(pixel)를 의미합니다.
- **너비 테스트**: 크롬 개발자 도구의 오른쪽 경계선을 잡고 드래그하면, 실제 기기 없이도 다양한 화면 크기에서의 모습을 즉시 확인할 수 있습니다.
---
### 4. 햄버거 메뉴(Hamburger Menu)의 마법
가장 흥미로운 부분은 화면이 좁아지면 글자로 된 메뉴가 사라지고 세 줄짜리 **'햄버거 아이콘'**이 나타나는 것입니다.

- **왜 햄버거인가요?** 세 개의 가로선이 빵-패티-빵 모양과 닮았기 때문입니다.
- **사이드 드로워(Side Drawer)**: 아이콘을 누르면 옆에서 메뉴가 슥 나타나는 방식입니다. 이번 모듈에서는 자바스크립트 없이 **HTML과 CSS만으로** 이 기능을 구현할예정
