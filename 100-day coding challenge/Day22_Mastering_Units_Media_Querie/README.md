## 1. 단위의 실전 배치 

### 단위의 핵심
#### 1.% & em
이 두 단위는 폰트 크기 맥락에서 쌍둥이처럼 작동함 즉 부모요소의 폰트크기만을 바라봄

100% = 1em
200% = 2em

**주의: 복리효과**

부모가2em이고 자식이 또 2em이면, 자식은 루트(html)대비 4배로 커짐

#### 2.rem
rem(Root em)은 부모가 누구든지 상관하지않음 오직 최상위 요소인`<html>`의 폰트크기만 참조함
장점 웹사이트 어디서든1.5rem은 항상 동일한 크기를 보여줌

### 폰트 크기 너머 단위의 차이

#### 1. %(퍼센트): 부모의 "너비"기준
가장 의외인 부분입니다. 패딩에 `%`를 쓰면 부모의 패딩이나 폰트 크기가 아닌, **부모 요소의 너비(Width)**를 기준으로 계산합니다.
- **계산**: 부모 너비가 $292px$일 때 `padding: 10%` $\rightarrow$ 약 $29.2px$
- **용도**: 화면 너비에 따라 여백이 줄어들거나 늘어나야 하는 유동적인 레이아웃에 적합합니다.

#### 2. em: 나 자신의 "폰트 크기"가 기준
`em`을 패딩에 쓰면 부모가 아닌 **현재 요소 자신의 폰트 크기**를 참조
- **계산**: 요소의 폰트 크기가 $44px$일 때 `padding: 0.1em` $\rightarrow$ $4.4px$ ($44 \times 0.1$)
- **용도**: 글자 크기에 맞춰 여백도 같이 커져야 하는 '컴포넌트 디자인'에 최적입니다. (예: 버튼 텍스트가 커지면 버튼 여백도 같이 커짐)

#### 3. rem: 언제나 변치 않는 "최상위(html)" 기준
`rem`은 어떤 속성에 쓰이든 상관없이 **오직 최상위($html$) 요소**의 폰트 크기만 바라봅니다.
- **계산**: $html$ 폰트 크기가 $22px$일 때 `padding: 0.1rem` $\rightarrow$ $2.2px$
- **용도**: 페이지 전체의 일관된 여백 시스템을 구축할 때 가장 안전합니다.

|**속성**|**사용 단위**|**선택 이유**|
|---|---|---|
|**Font Size / Spacing**|**$rem$**|사용자의 브라우저 폰트 설정에 비례하여 크기가 변해야 함.|
|**Layout Width / Padding**|**$\%$**|화면 전체 너비(Viewport)에 따라 유동적으로 요소가 채워져야 함.|
|**Border Radius**|**$px$**|요소가 커진다고 해서 테두리 곡률까지 비례해서 커지면 디자인이 왜곡될 수 있음(고정된 시각적 디테일 유지).|

## 2. 설계 철학: Desktop vs Mobile First 
반응형 웹을 설계할 때 가장 먼저 결정해야 할 전략적 선택지가 바로 **'어떤 화면을 기준으로 코딩을 시작할 것인가'**입니다. 단순히 크기의 문제가 아니라, 사용자에게 전달하려는 가치와 환경에 따라 접근 방식이 완전히 달라집니다.

### 1. 두 전략의 핵심 개념

- **Desktop First (데스크톱 우선)**: 큰 화면(PC)을 기준으로 모든 기능을 다 넣은 웹사이트를 먼저 개발한 뒤, 화면이 좁아짐에 따라 요소를 숨기거나 크기를 줄여나가는 방식입니다.
- **Mobile First (모바일 우선)**: 가장 작은 화면(스마트폰)을 기준으로 필수적인 핵심 콘텐츠만 먼저 담아 개발한 뒤, 화면이 넓어짐에 따라 레이아웃을 확장하고 기능을 추가하는 방식.

### 2. 전략 비교: 무엇이 다른가?

|**특징**|**Desktop First (전통적)**|**Mobile First (현대적 표준)**|
|---|---|---|
|**주요 타겟**|사무실 기반, 전문적인 작업자|라이프스타일, 뉴스, SNS 사용자|
|**디자인 철학**|**기능 중심** (넓은 공간 활용)|**콘텐츠 중심** (제한된 공간 활용)|
|**접근 방식**|하향식 (감축 및 축소)|상향식 (확장 및 추가)|
|**적합한 서비스**|코딩 강의, 관리자 페이지, 복잡한 툴|인스타그램, 틱톡, 뉴스 미디어|

## 3. 반응형의 심장: 미디어 쿼리 
### 1. 미디어 쿼리의 기본구조
```CSS
@media (조건: 너비값) {
  /* 이 조건이 참(True)일 때만 실행될 CSS 규칙 */
  selector {
    property: value;
  }
}
```
### 2. 전략에 따른 키워드 선택

|**전략**|**키워드**|**작동 방식**|
|---|---|---|
|**Desktop First**|**`max-width`**|"너비가 **최대 X**일 때까지만 적용해" (큰 화면 → 작은 화면으로 줄여나갈 때)|
|**Mobile First**|**`min-width`**|"너비가 **최소 X**는 넘어야 적용해" (작은 화면 → 큰 화면으로 키워나갈 때)|

미디어 쿼리는 기존 코드를 삭제하는게 아닌 덮어쓰거나 추가하는것
따라서 쿼리 내부에 명시하지않은 속성들은 이전의 기본 스타일을 그대로 물려받음

### 3. 표준 브레이크포인트 (Standard Breakpoints)

|**장치 유형**|**추천 브레이크포인트**|**비고**|
|---|---|---|
|**모바일 (Smartphone)**|`480px` (또는 `30rem`)|주로 세로 모드 대응|
|**태블릿 (Tablet)**|`768px` (또는 `48rem`)|아이패드 등 태블릿 기기|
|**노트북 (Laptop)**|`1024px` (또는 `64rem`)|작은 화면의 랩탑|
|**데스크톱 (Desktop)**|`1200px` (또는 `75rem`)|대형 모니터|
