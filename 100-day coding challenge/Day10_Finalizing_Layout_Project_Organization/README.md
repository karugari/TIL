# Day 10: Finalizing Layout & Project Organization
## 1. 메인 콘텐츠 스타일 및 박스 모델 (Main Content & Box Model)
웹 페이지의 핵심인 본문 영역을 카드 형태로 디자인하고 박스 모델을 정교하게 제어하는 방법을 학습했습니다.

본문 카드 디자인:
background-color: 구역 구분을 위한 배경색 적용.
padding: 콘텐츠와 테두리 사이의 숨통을 틔워주는 내부 간격.
width: 화면 전체를 채우지 않도록 700px로 너비를 고정하여 가독성 확보.
border-radius: 딱딱한 사각형 대신 부드러운 모서리 곡률 적용.
color: 배경색과 대비되는 텍스트 색상 설정.

## 2. 블록(Block) vs 인라인(Inline) 정렬
요소의 성격에 따라 중앙 정렬을 구현하는 방식이 근본적으로 다름을 이해했습니다.
|요소 타입|대상 예시|정렬 방법|특징|
| :--- | :--- | :--- | :--- |
|인라인 요소|"텍스트, 이미지 등"|부모 요소에 text-align: center 적용|콘텐츠 자체만 중앙으로 이동함|
|블록 요소|"main, div, h2 등"|본인에게 margin: auto (좌우 여백 자동) 적용|상자(Box) 전체가 중앙으로 배치됨|

핵심 트릭: main 요소에 text-align을 적용하면 내부 텍스트만 중앙으로 가고 상자 자체는 왼쪽에 머뭅니다. margin: auto를 설정해야 브라우저가 남은 여백을 좌우에 똑같이 배분하여 상자 전체를 중앙에 놓습니다.

## 3. 리스트 및 세부 스타일링 (List & Detail Styling)
브라우저 기본 스타일을 초기화하고 클래스를 활용해 특정 요소만 정밀하게 타격하는 테크닉을 익혔습니다.
리스트 초기화: 디자인 자유도를 높이기 위해 ul의 기본 여백(margin, padding: 0)과 불릿(list-style: none)을 제거합니다.
투명 테두리 트릭: 특정 항목(li)에만 테두리를 넣을 때 텍스트 정렬이 어긋나는 것을 방지하기 위해, 모든 항목에 미리 **투명한 테두리(transparent)**를 설정한 뒤 색상만 변경합니다.
상속의 예외 (Anchor Tag): 부모의 color를 설정해도 <a> 태그는 브라우저 기본 색상이 우선순위가 높으므로, 반드시 직접 선택하여 스타일을 지정해야 합니다.
가상 클래스 (Pseudo-classes): 사용자의 상호작용(:hover, :active)에 따른 변화를 정의합니다.

## 4. 의미론적 태그와 구조 개선 (Semantic HTML)
시각적인 디자인을 넘어 컴퓨터와 보조 기술이 이해할 수 있는 구조를 설계합니다.
푸터 및 링크 확장:
<footer> 내부에 다운로드 링크와 저작권 문구 배치.
target="_blank": 현재 페이지를 유지한 채 새로운 탭에서 링크를 열도록 설정.
강조 태그의 의미:
span: 의미 없는 단순 스타일용.
em (Emphasize): 톤을 변경하는 강조 (글자 기울임).
strong: 강한 어조의 강조 (볼드체 처리 및 보조 기술에 전달).
구조적 섹션화 (<section>): 논리적인 콘텐츠 덩어리를 구분하여 개발자와 브라우저의 코드 해석 능력을 높입니다.
