MDN 문서에서 보셨듯이, 현대 웹사이트는 누구나 이해할 수 있는 공통된 구조를 따릅니다. 우리가 만들 **'Travel Goals'** 페이지도 이 3가지 기둥을 중심으로 설계됩니다.

2. **`<main>`**: 이 페이지의 존재 이유인 핵심 콘텐츠가 담깁니다.

    - **`<section> 2` (Highlights)**: 추천 여행지 카드들이 나열되는 영역입니다.
3. **`<footer>`**: 페이지 하단의 정보 영역입니다. SNS 링크나 저작권 정보가 들어갑니다.
## 2. CSS flexbox:레이아웃의 혁명
플렉스 박스를 이해하는 가장 중요한 열쇠는 **'누가 부모(Container)이고 누가 자식(Items)인가'**를 구분하는 것입니다.
### [1] 부모(Container)와 자식(Items)
- **Flex Container (부모)**: `display: flex;`가 선언된 요소입니다. 이 박스는 자식들을 어떻게 배치할지 결정하는 '관리자'가 됩니다.
- **Flex Items (자식)**: 컨테이너 바로 아래에 있는 직계 자식들입니다. 부모의 명령에 따라 유연하게 움직입니다.
### [2] 두 개의 축 (Main Axis & Cross Axis)

플렉스 박스에서 요소를 정렬할 때 길을 잃지 않으려면 **'축'**의 개념을 반드시 잡아야 합니다.
1. **주축 (Main Axis)**: 요소들이 나열되는 기본 방향입니다. (기본값: 가로)
2. **교차축 (Cross Axis)**: 주축과 직각을 이루는 방향입니다. (기본값: 세로)

> **주의!** 이 축은 고정된 것이 아니라 `flex-direction` 설정에 따라 바뀝니다.
### [3] 방향 제어 (`flex-direction`)
요소를 가로로 쌓을지, 세로로 쌓을지 결정합니다.

| **값**                | **설명**      | **주축 방향** |
| -------------------- | ----------- | --------- |
| **`row`** (기본값)      | 왼쪽 → 오른쪽 나열 | 가로        |
| **`row-reverse`**    | 오른쪽 → 왼쪽 나열 | 가로 (반대)   |
| **`column`**         | 위 → 아래 나열   | 세로        |
| **`column-reverse`** | 아래 → 위 나열   | 세로 (반대)   |
### 4. 줄 바꿈과 단축 속성

- **`flex-wrap`**: 요소들이 컨테이너 너비를 넘쳤을 때 줄을 바꿀지 정합니다.
    - `nowrap` (기본값): 억지로 한 줄에 우겨넣습니다.
    - `wrap`: 자리가 부족하면 다음 줄로 넘깁니다.

- **`flex-flow`**: `direction`과 `wrap`을 한 번에 쓰는 단축 속성입니다.
    - 예: `flex-flow: row wrap;`
## 3. Aligning Flex Items (정렬의 기술)

### ↔️ 1. 주축 정렬: `justify-content`
주축(Main Axis, 가로 방향이 기본)을 기준으로 아이템들 사이의 **여백**을 어떻게 분배할지 결정합니다.

- **`flex-start` (기본값)**: 아이템들을 시작점으로 밀착시킵니다.
- **`flex-end`**: 아이템들을 끝점으로 밀착시킵니다.
- **`center`**: 아이템들을 중앙으로 모읍니다.
- **`space-between` (가장 많이 사용)**: 양 끝 아이템을 벽에 붙이고, 나머지 여백을 아이템 사이에 **동일하게** 배분합니다. (로고와 내비게이션 바 배치에 최적!)
- **`space-around`**: 각 아이템의 좌우에 동일한 여백을 둡니다. (아이템 간의 간격이 양 끝 간격보다 넓어짐)
- **`space-evenly`**: 모든 여백(양 끝 포함)을 완전히 동일하게 맞춥니다.
---
### ↕️ 2. 교차축 정렬: `align-items`

교차축(Cross Axis, 세로 방향이 기본)을 기준으로 아이템들의 **높낮이**를 어떻게 맞출지 결정합니다.

- **`stretch` (기본값)**: 컨테이너의 높이에 맞춰 아이템들이 위아래로 길어집니다.
- **`flex-start`**: 아이템들을 위쪽으로 붙입니다.
- **`flex-end`**: 아이템들을 아래쪽으로 붙입니다.
- **`center`**: 아이템들을 **수직 중앙**에 정렬합니다. (로고와 메뉴의 텍스트 높이를 맞출 때 필수!)
